# Convenzione Linguistica del Codice

## Decisione

Per questo progetto, il linguaggio descrittivo interno al codice backend deve essere italiano.

Questo include:

- commenti
- docstring
- messaggi di errore applicativi
- messaggi di log
- note e descrizioni OpenAPI

## Non include

- nomi di moduli framework
- identificatori tecnici che seguono convenzioni Python o FastAPI
- nomi di file e directory gia coerenti con struttura tecnica standard

## Motivazione

Il team lavora primariamente in italiano e il codice deve restare leggibile anche a chi si occupa di dominio, migrazione e manutenzione operativa, non solo di sviluppo moderno.
