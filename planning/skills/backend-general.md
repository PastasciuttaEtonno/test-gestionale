# Skill: Backend General

## Obiettivo

Scrivere backend coerente con `FastAPI + Pydantic + SQLAlchemy`.

## Regole

- endpoint sottili
- servizi applicativi centrali
- repository per accesso dati
- schemi Pydantic per contratti API
- modelli SQLAlchemy per persistenza
- commenti, docstring, messaggi applicativi e note di logging in italiano

## Da evitare

- logica di business nei router
- query SQL negli endpoint
- ritorno diretto di entita ORM al client
